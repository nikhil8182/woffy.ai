# Premium AI Screen Design — "Jarvis-Class Polish"

**Date:** 2026-03-03
**Target:** `src/pages/ChatWithWoffy.jsx` + `src/index.css`
**Direction:** Refined Sci-Fi — keep the soul, elevate the execution

## Design Principles

- Every element gets a systematic premium upgrade
- Keep Woffy's unique sci-fi personality (neural orb, HUD sidebar, particle network)
- Feel: Polished Iron Man / Apple Vision Pro
- Tech: Tailwind CSS + Framer Motion (no new dependencies)

## 1. Boot Sequence — "Dramatic Initialization"

- Glitch text effect: characters scramble before resolving to real text
- Pulsing concentric ring animation behind loading (radar ping)
- Faster cadence: 500ms per step (down from 800ms)
- Dramatic exit: zoom-burst outward (scale up + fade)
- Sound-wave equalizer bars replacing single progress bar
- Version + codename flair text ("CODENAME: TITAN")

## 2. Neural Orb — "Living Intelligence Core"

- Multi-layered frosted glass core with inner shadow + refractive highlight
- Breathing animation: constant gentle scale pulse (1.0 → 1.02 → 1.0)
- Enhanced state transitions with color shifts (idle: indigo, thinking: purple-cyan cycle, speaking: violet-pink)
- Particle halo: tiny dots orbiting outer ring, speed up during thinking
- Reflection spot: slow-rotating white highlight simulating light on glass
- Ripple effect on state transitions

## 3. Chat Messages — "Premium Conversation"

- AI messages: frosted glass + inner glow + thin gradient top-border (indigo → purple)
- User messages: richer gradient (indigo → violet → purple) + soft outer glow
- Avatar rings: Woffy gets pulsing indigo ring, user gets subtle white ring
- Message entrance: spring animation + blur-to-clear materialization
- Hover state: subtle lift (translateY -1px) + enhanced shadow
- Timestamps: relative time ("just now", "2m ago"), fade-in on hover
- Thinking indicator: waveform/particle orbit instead of bouncing dots
- Typewriter: blinking cursor at end while typing

## 4. Input Area — "Command Dock"

- Animated gradient border on focus (indigo → purple → cyan rotation)
- Floating glass dock with pronounced backdrop blur + premium shadow
- Voice button: ripple on click, pulsing glow when listening
- Send button: scale animation on click
- Auto-resize textarea (up to 4 lines)
- Suggestion chips: glass cards + animated icon + gradient border reveal on hover
- Subtle "Press Enter to send" hint after 2s inactivity

## 5. Sidebar HUD — "Mission Control"

- Module badges: animated status pulse, hover tooltip
- Event log: live-updating, entries slide in with highlight flash
- Section dividers: gradient lines instead of plain borders
- Sidebar toggle: glass pill button
- Footer stats: "Messages: X" and "Session: Xm" live counters

## 6. Global Refinements

- Typography: tighter heading tracking, 15px message text, refined monospace
- Scrollbar: dark custom scrollbar with indigo tint
- Background particles: depth effect (larger foreground, smaller background)
- Ambient glow: slow-moving gradient orbs in background
- Focus management: indigo ring focus indicators
